# Roadmap

## v0.2 当前完成

- 高德真实地点、天气、步行路线。
- OpenAI-compatible AIGC 策略生成。
- AIGC 商品需求生成。
- 严格真实数据模式。
- SQLite 推荐历史、反馈、饮食记录和 Provider 缓存。
- 前端定位、推荐、反馈闭环。
- 前端快速记录饮食，推荐自动读取近期饮食标签。
- `request_id` 驱动的“换一批”替代推荐。
- 推荐评估脚本：预算、距离、数据来源、排除项和健康冲突。
- Docker、CI、测试和公开密钥扫描。

## v0.3 推荐下一步

- PostgreSQL 适配：支持多人部署。
- 驾车、公交、骑行路线。
- 用户数据导入：运动、睡眠、日历。

## 长期方向

- 向量检索和语义召回。
- 多 Agent 任务规划：餐厅、路线、购物、旅行分工协作。
- 真实商品 Feed 导入。
- 商家菜单和营养数据合作接入。
- 移动端或小程序端。
