# 隐私与安全策略

LifeRec 涉及饮食、地点、预算和生活习惯，因此默认策略是本地优先、最小化收集。

## 当前版本

- 使用本地 JSON 示例数据。
- 不上传用户真实生活记录。
- 不保存精确定位轨迹。
- 浏览器当前位置只在用户点击“使用当前位置”后用于当次推荐请求。
- 第三方地图、天气或电商 API 接入前，需要在产品界面说明数据会发送到哪个服务商。
- 不提供医疗诊断。
- 不生成处方、治疗方案或高风险健康建议。

## 开发建议

- 真实部署时应提供用户数据删除能力。
- 健康建议必须保留免责声明。
- 地点数据应只在用户明确授权时使用。
- 第三方地图、电商或外卖 API 应清楚标注数据用途。
